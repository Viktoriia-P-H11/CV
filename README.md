## 🌟 Featured Projects

### 1. [Haugaland SmartKommune](https://haugaland-smart-kommune.vercel.app/)
*Municipal & Citizen Energy Intelligence Hub (Haugesund & Rogaland / NO2 Zone)*
- **Live Site:** [https://haugaland-smart-kommune.vercel.app/](https://haugaland-smart-kommune.vercel.app/)

- **Weather & Forecast:** Live local Haugesund weather via Open-Meteo REST API.

## 🚀 Local Development

To run this portfolio locally:

```bash
# Clone the repository
git clone https://github.com/Viktoriia-P-H11/CV.git

# Open directory
cd CV

# Serve with any static web server (e.g., Python, Node, VS Code Live Server)
npx serve .
# or
python -m http.server 8000
```
Open `http://localhost:5175` (or whichever port was specified) in your browser.
